The v0.15.2 seed checks a const field only on `obj.f` outside a constructor of its class. From 0.16 (fly-lang/fly#240) a static const is set by its initializer alone, and an instance const once, by a constructor of its class, on its own object (`this.v` or the bare name), and only when it has no initializer: every other write is err_sema_const_assign.
